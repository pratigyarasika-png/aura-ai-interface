# Aura AI Interface

Build the core layout and responsive UI shell for an AI Academic Research Platform. The visual identity must be completely original with a unique circular/rounded aesthetic, strictly avoiding any cloning of SciSpace's design.

Key UI components to build:

1. Header: Clean navigation bar with custom background color picker (light/dark/custom hex accent) and Google OAuth login avatar placeholder.

2. Circular AI Hub: Floating circular action widgets and rounded control panels with sleek micro-interactions.

3. Sidebar: Collapsible navigation bar containing history categories, saved projects, and recent research sessions.

4. Top Status Bar: Live Activity badge showing background tasks (e.g., "Scraping papers...", "Generating citations...", "Synthesizing PDF...").
